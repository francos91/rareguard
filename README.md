# RareGuard

> Rare-event anomaly detection with cost-calibrated alerting, validated on
> rail telemetry and bank account fraud data. The contribution is not the
> detector — it is the threshold calibration layer, which maximises expected
> monetary value subject to a fixed operator inspection budget.
